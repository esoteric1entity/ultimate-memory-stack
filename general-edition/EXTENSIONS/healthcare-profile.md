# EXTENSION — Healthcare Profile (for General-Edition)

> **File:** `general-edition/EXTENSIONS/healthcare-profile.md`
> **Status:** Not available in general-edition

---

PHI/HIPAA compliance is **not** part of general-edition. The installer does not accept the `healthcare` preset or the `healthcare` extension.

A HIPAA/PHI-focused institutional edition is planned for a future release (not yet available). See CONTRIBUTING.md.

The general-edition supports the `none`, `enterprise`, and `custom` compliance presets and the `gdpr` / `soc2` / `pci-dss` extensions.
